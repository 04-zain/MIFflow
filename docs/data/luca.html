LuCa example image

Source image

The stage guides use the PerkinElmer field LuCa-7color_[13860,52919]_1x1component_data.tif from the OME Vectra sample collection. The dataset is attributed to PerkinElmer under CC BY 4.0 in QuPath's image acknowledgements.

Stored component type float32
X and Y pixel size Approximately 0.498 µm
Component state Already unmixed; vendor pages record IsUnmixedComponent=True
Processing input Original vendor TIFF, analytical series 0

The two-image examples also use LuCa-7color_[17572,60173]_3x3component_data.tif, a 5604 × 4200-pixel field with the same eight-channel panel and approximately 0.498 µm pixel size. These fields use separate image identities within the same subject in the walkthrough.

Prepare the vendor image

Download the original TIFF and add it on Samples. Its sole eligible analytical image is selected automatically; the other series is an RGB thumbnail. If a file contains several eligible images, choose the images to add from the selection dialog. Complete Channels and markers, retaining the already-unmixed image state and assigning the markers listed below.

Preparation writes the supplied component intensities to OME-Zarr, preserving channel order and physical calibration. The vendor's zero exposure values are treated as unavailable exposure times. Choose whether to display marker names with the channel-name option. Image processing explains how we read and write the image in regions.

Examples in the guides

The LuCa walkthrough illustrates tissue detection, cell segmentation, measurement selection and marker decisions. The guides identify the field, selected population and settings beside each result. Some method comparisons use a separately segmented population from the same source field:
