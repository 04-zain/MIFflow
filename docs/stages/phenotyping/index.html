Cell phenotyping

Analysis stages

Cell phenotyping assigns biological labels to segmented cells from their staining and, for some classifiers, their shape.

Choose a phenotyping method

On Run → Cell phenotyping → Open review, choose how to identify phenotypes in the cells included in your analysis.

Marker rules suit phenotypes defined by known combinations of positive and negative markers. For each marker, set a threshold on the measured staining intensity or on the expression score estimated by Nimbus. Then specify the marker combination that determines each phenotype.

Supervised classification is appropriate when the phenotypes are already defined and you can label representative cells for each one. It is particularly useful when cells of the same phenotype vary in staining intensity or when distinguishing two phenotypes depends on several measurements together. Label examples of that variation in QuPath so the classifier can learn which patterns distinguish the phenotypes and recognise them in other cells.

Unsupervised phenotyping is useful when the cell populations are unknown or when a known population may contain subgroups with distinct marker profiles. PhenoGraph or FlowSOM groups cells with similar marker measurements. Compare the groups’ marker profiles and examine their staining in tissue to determine which groups represent distinct phenotypes and which can share a name.

How the methods use cell measurements and images

The cell ID links each row in the measurement table to the corresponding segmented outline in the marker images.

Saved cell measurements. Marker thresholds and unsupervised phenotyping use the mean or median marker intensity measured within the selected part of each cell, such as its nucleus or whole-cell outline. Supervised classifiers can also use other intensity statistics and measurements of cell or nuclear shape. If a measurement you want to use is missing, calculate it in Cell measurements before fitting.

Features from cell images and outlines. For marker rules, Nimbus uses the marker image and segmented outlines to estimate an expression score for each cell. You can threshold this score directly or fit an intensity threshold to the reviewed Nimbus decisions. For supervised classification, KRONOS encodes the staining within each reference cell’s outline across the selected channels. The classifier learns to predict phenotype labels from these features and uses the same encoder for the cells it will classify.
