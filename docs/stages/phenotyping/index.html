Phenotyping methods and included cells

Analysis stages

Open: Run → Cell phenotyping → Open review.

Cell phenotyping assigns biological labels to segmented cells using their measurements or marker images. Marker rules define phenotypes through combinations of marker states, supervised classifiers learn from labelled reference cells, and unsupervised methods group cells by their measurements for subsequent naming.

On this page: Select cells · Choose a method · Choose measurements.

Select cells to phenotype

Cell phenotyping initially includes all segmented cells from the accepted analysis regions. To analyse only particular primary tissue classes, enable Restrict to selected regions and select the classes to include.

We include cells whose centres lie inside a selected region or on its boundary, counting each cell once even where regions overlap. Other cells remain Not phenotyped. When comparing phenotype frequencies across images, check that each image includes the intended regions. An image with no regions of the selected classes contributes no cells to the comparison.

The saved measurements record which tissue and primary tissue regions contain each cell. After changing those regions, recalculate the affected measurements before using the new regions to select cells. Changing a completed step explains how to review the affected results.

Choose a phenotyping method

Choose Marker rules, Supervised classification or Unsupervised phenotyping according to how you will define the phenotypes.

Method Inputs and decisions
Marker thresholds and rules Set a positive/negative decision for each marker, then combine markers into phenotype rules.
Supervised cell phenotypes Label reference cells and fit RF, SVM or LR using their measurements or KRONOS image embeddings.
Unsupervised phenotyping Group cells with similar marker measurements, then assign phenotype names from their profiles and staining.

Choose the phenotyping inputs

The selected method determines whether phenotyping uses saved Cell measurements or features calculated from cell images and outlines.

Marker thresholds and unsupervised phenotyping use saved Mean or Median marker intensities. Supervised RF, SVM and LR classifiers can also use the other saved intensity statistics and cell or nuclear shape measurements. To use a measurement that has not been calculated, return to Cell measurements, revise its choices and calculate the additional result before continuing phenotyping.

The image-based routes use the staining around each segmented cell. For supervised classification, KRONOS encodes the masked marker images into features that the classifier can learn from the labelled reference cells. For marker rules, Nimbus uses the marker image and cell mask to estimate an expression score. Neither model needs saved intensity or shape measurements to calculate its output. For Nimbus review, we also retrieve the saved Mean or Median to compare the scores with cell intensity and optionally fit an intensity gate.
