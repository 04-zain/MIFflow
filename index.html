MIFflow

MIFflow is a platform for multiplex immunofluorescence (mIF) that integrates and extends methods for image processing, quantitative analysis and reviewing within a semi-automated workflow.

Preparing an analysis

Create an analysis on Home. Add the images and their subject IDs on Samples, then review the planned stages on Plan.

Guide Purpose
Create an analysis and add samples Create an analysis folder, add the images, identify which samples belong to each subject and choose which images to process together.
Local and cluster computing Run the desktop on your computer or on a cluster, or keep the desktop on your computer and send processing jobs to the cluster.
Run, review and continue Follow progress, inspect completed stages and reopen a saved analysis to continue work or revise a decision.

Analysis stages

Follow the stages on Run to prepare the images, identify tissue and cells, and review their measurements and phenotypes.

Stage Analysis
1 · Image inspection Inspect the image, channel metadata and physical pixel sizes.
2 · Channels and markers Identify the fluorophores and their biological markers, then select the nuclear stain.
3 · Spectral unmixing Separate overlapping fluorescence signals using imported spectra or a library prepared from reference images.
4 · Tissue detection Separate tissue from background using an intensity threshold or a trained detector.
5 · Image alignment Align a paired image, such as H&E, to the mIF image for display and transferring annotations.
6 · Analysis regions Use whole tissue sections or select smaller regions within them for analysis.
7 · Tissue classification Annotate examples of each tissue class, fit a classifier using image features or KRONOS, and inspect its predictions.
8 · Cell segmentation Segment cells or nuclei with InstanSeg, Cellpose-SAM or StarDist. Inspect the outlines and edit them where needed.
9 · Cell measurements Measure marker intensity in the selected cell compartment and calculate shape measurements from the cell and nuclear outlines.
10 · Cell phenotyping Assign phenotypes using marker rules, supervised classification or unsupervised clustering. Marker rules can use cell intensities or Nimbus marker scores.
11 · Secondary structures Define and detect structures within tissue, review their cell populations and regional measurements, and assign subtypes where relevant.
12 · Results and export Export measurements, phenotypes and regional summaries, or create figures from a completed stage.

Architecture and data flow

We use Python, Java and Groovy to run the desktop and perform image and cell analyses. QuPath provides the image viewer, annotation tools and prediction overlays used during review. The processing guide explains how our scripts and compiled methods carry out each stage and how they interact.

Topic Technical guides
Images and spectral references Reading source images, spectral fitting and intensity correction, and storing and reading OME-Zarr image regions
Fitting and applying classifiers RF, SVM and logistic regression and tissue-model features and fitted parameters
Cells and annotations Assembling outlines across segmentation tiles and loading and editing regions in an image
Saved results Image, model and table formats and reading cell geometry, measurements and phenotype assignments
Computing and recovery Memory and simultaneous calculations, scheduling and reuse of results, and resuming interrupted work

Building and integration

To install MIFflow from source, first build the QuPath extension, then install the Python application. To distribute MIFflow, follow the build and release guide to create a wheel for an existing Python environment or a portable desktop archive for Windows or Ubuntu.

Use the command-line programs to run a prepared analysis on a processing host. The Python interfaces let another program read saved results or call individual analysis methods.
